# 開発記録

## 2026-11-24 — 論文の内容に合わせたグラレコ枚数

- 全文JSONの作成時に、同じ問いでも対象集団や治療条件を1枚で取り違える場合は図を分ける。広い論文はテーマ図2〜4枚を目安とし、さらに必要なら理由を添える。全体図は複数テーマの関係を示す場合に加える。PNG作成画面に合計と全体図の内訳、新規取り込み分には題名と構成の理由を表示。

## 2026-11-24 — 全文JSONの一括見積もりと送信

- ローカル概算が長文料金域に達したPDFも最大5本の一括見積もりに含め、送信確認後に実入力を計測。既存の予算・入力制限を各論文に適用し、実入力超過時はほかの論文を進めながら、該当論文の処理履歴からWebで全文JSONを依頼できる。旧版の保留一覧にも一括再見積もりを追加。

## 2026-11-23 — JSON Batch候補一覧の表示改善

- 選択・PMID・論文タイトル・種別の列を揃え、PubMedの種別詳細とタイトルからの推定を区別して表示。候補一覧からPubMedの書誌をまとめて更新できるようにした。

## 2026-11-23 — レビューの読書ガイドと長文の送信前確認

- PubMedのPublication Typeと抄録を取得し、原本や工程履歴とは独立したPMID別の書誌情報として共有。読書ガイドの画面から抄録・PDFのしおり・全文JSONの一行要約を確認し、短いガイドの依頼をコピーできる。
- Batchの準備時にレビューを含む各論文の種別を表示。既存のローカル入力見積もりが長文料金域を超えるPDFは送信候補から保留し、理由と読書ガイドへの導線を表示する。明示的に選んだ1本は従来の実入力計測と予算確認に進める。
- 選択した原本PDFのページから、出典ページを明記する短い読書ガイドまたは部分図解の資料と依頼文をMacに保存。部分図解は個人の読書用とし、全文JSON・PNG承認・Notion登録の完了記録から独立させた。

## 2026-11-21 — Web生成PNGの医学的照合

- テーマごとの元JSONから、PMID・対象・主題・結果・推奨・限界・日本への適用とPractice Changeの必須表示を抽出する。Overviewと個別テーマの評価を分け、null・欠落を「未評価」とする。
- Macの取り込み時にApple VisionでPMIDとPractice Changeの明らかな不一致を検出する。PNGは候補として保管し、人が画像内の値を読み取り、固定情報と照合した版だけを正式PNGとして選ぶ。手動完了・Notion登録でも承認を確認する。
- 実際の40317496（Overview）と40066935（屋外介入）の画像用JSONを読み取り専用で確認。合成PNGでは「未評価」に対する「Yes」をVisionで検出し、テスト用の画面で固定情報の表示から承認まで確認した。

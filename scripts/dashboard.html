PubMed GraRec Notion

PDF → JSON → PNG → 確認・手動登録 ｜ OneDriveで自宅と職場をつなぐ

処理は自分で1工程ずつ進めます。ファイルを保存すると約30秒ごとに工程を記録します。端末を切り替える前にOneDriveの同期完了を確認してください。Mac停止中は最後に同期されたファイルと記録を利用できます。

1　論文を追加・ファイルを受け渡す

各論文の「受け渡しフォルダ」にPDF・JSON・PNGを保存します。JSON作成時は依頼文とPDFをChatGPT Webへ渡し、完成した master.json をJSONフォルダへ。画像作成時はテーマ別の依頼文を渡し、テーマID.png をPNGフォルダへ保存してください。

新規JSONは既存のMaster JSON形式を使います。保存済みファイルは版ごとに保持します。内容の確認とNotionへのアップロードは手動です。
PMIDを追加する／PubMed AbstractのTXTを選ぶ

2　論文一覧

PMID・論文現在の工程・最終更新ファイル・保存場所手動操作

3　このMacの設定

OneDrive共通フォルダ・端末名

自宅と職場で同じOneDriveの PubMed_GraRec フォルダを指定します。各Macの保存パスは違っていても構いません。初回は空の専用フォルダを使用します。

旧台帳と元ファイルは保持します。共有フォルダに登録済みのPMIDは上書きしません。APIキー・SQLite台帳は共有しません。
OneDriveへの保存とクラウドへの同期完了は別です。この画面の時刻は各Macで記録した時刻です。iPhone・iPadはPubMed 進捗で同じ分類の件数を確認できます。状況共有を設定したMacのアプリ起動中に約30秒ごとに共有します。論文ファイルはOneDriveの「papers」内を利用してください。

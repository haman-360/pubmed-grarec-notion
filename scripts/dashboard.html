PubMed GraRec Notion

PDF → JSON → PNG → 確認・Notion登録 ｜ OneDriveで自宅と職場をつなぐ

どの端末でもOneDriveの「00_取り込み待ち」へ保存できます。Macで「取り込み・整理」を押すと、途中の工程をまとめて進められます。Mac停止中もアップロード済みのファイルを閲覧できます。工程の件数は次の整理まで変わりません。

工程を選んで進める

1　PDF取得待ち入手したPDFを取り込み待ちへ保存
2　JSON作成待ち一覧の依頼文とPDFをChatGPT Webへ
3　PNG作成待ちテーマごとに作成し、テーマID.pngで保存
4　確認・登録待ち原文と照合し、Notionへアップロード
5　登録完了一覧の「確認・登録の記録」で完了を記録

PDF自動取得・JSON Batch・確認後のNotion登録が利用できます。PNGはWeb等で手動作成します。

PDFからJSONを作成する — Batch API

PDF取得済み・JSON未作成の論文を最大5本選びます。API担当Macから送信・回収します。送信後はMacを停止してもAPI側の処理は続き、担当Macで回収するとOneDrive保存と工程更新を行います。手動作成も引き続き利用できます。

APIキー・担当Mac・予算の設定

担当Macのリポジトリ直下の .env に OPENAI_API_KEY を設定してください。キーと費用台帳はこのMac内に保存します。初回は1台だけで設定し、OneDrive同期後に他のMacを開いてください。

期間$20・1処理版$4まで。残高の確認は24時間有効です。見積もりは請求上限の保証ではありません。

回収はこのボタンを押したときだけです。JSON保存済みならPNG作成待ちへ進みます。手動作成・原本差し替え等が先にあった場合はAPI結果を候補として残します。

PNGを確認してNotionへ登録する

全テーマのPNGが揃った論文を最大5本選びます。登録内容の確認で、登録先と既存ページを照合します。その後、PNGを1枚ずつ原文・JSONと照合して登録してください。同じ論文の再実行は既存ページ・添付を照合して再開します。

Notion接続の設定

担当Macの .env の NOTION_TOKEN・NOTION_DATABASE_ID を使います。複数データソースがある場合は NOTION_DATA_SOURCE_ID も必要です。登録先には接続のアクセス権と、PMID・Automation ID（どちらもテキスト型）が必要です。DB構造は自動変更しません。最初に登録内容を確認したMacが担当になります。1台で設定してOneDriveの同期完了を待ってください。手動登録はどの端末でも続けられます。

新規ページのHuman Checkedはオフのままです。PNGの確認記録と、論文全体の医学的な確認は区別します。既存ページの内容は保持し、この版のテーマ・添付を追加します。PDFはOneDriveに保管します。

PDFを自動取得する

PDF取得待ちの論文を選び、下のボタンで開始します。公開PDFを順番に検索し、OneDriveの共通フォルダへ保存します。認証が必要な論文は手動取得へ引き継ぎます。処理中はこのMacのアプリを開いておいてください。

OneDriveの 00_取り込み待ち/PMID_番号/ にPDF・master.json・テーマID.png・メモ.txtを保存します。PDFだけでも、完成した一式でも取り込めます。希望PMIDのTXTは取り込み待ちへ直接保存できます。整理に成功した入力は 01_取り込み済み に保管します。

PMIDが不明・候補が複数・保存や同期の途中の場合は入力を残します。メモだけでは工程を完了にしません。既存の論文別「受け渡しフォルダ」も引き続き約30秒ごとに確認します。共通の取り込み待ちを整理するのは上のボタンまたは「取り込み・整理.command」を実行したときです。

このMacの設定

OneDrive共通フォルダ・端末名

自宅と職場で同じOneDriveの PubMed_GraRec フォルダを指定します。各Macの保存パスは違っていても構いません。初回は空の専用フォルダを使用します。

旧台帳と元ファイルは保持します。共有フォルダに登録済みのPMIDは上書きしません。APIキー・SQLite台帳は共有しません。
OneDriveへの保存とクラウドへの同期完了は別です。この画面の時刻は各Macで記録した時刻です。iPhone・iPadはPubMed 進捗で同じ分類の件数を確認できます。状況共有を設定したMacのアプリ起動中に約30秒ごとに共有します。論文ファイルはOneDriveの「papers」内を利用してください。
